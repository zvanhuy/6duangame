2. SCRIPT ĐÃ ĐƯỢC TÁCH RA

Assets/Scripts/QuanLyTroChoiBanBong.cs
- Gắn trên object: Quản lý trò chơi.
- Nhiệm vụ: điều phối game, khởi tạo game, xử lý thắng/thua, chơi lại.
- Không còn ôm toàn bộ logic như bản cũ.

Assets/Scripts/TrinhTaoCauTrucBanBong.cs
- Script tạo cấu trúc Hierarchy tiếng Việt.
- Tạo Camera, đèn, nền, tường, súng, canvas, bảng thua/thắng, các khung UI.

Assets/Scripts/QuanLyLuoiBong.cs
- Gắn trên object: Quản lý trò chơi.
- Nhiệm vụ: tạo lưới bóng, lưu vị trí hàng/cột, gắn bóng vào lưới, tìm cụm cùng màu, xóa bóng.

Assets/Scripts/QuanLyBongBan.cs
- Gắn trên object: Quản lý bóng bắn.
- Nhiệm vụ: quản lý Bóng đang bắn và Bóng xem trước.

Assets/Scripts/DieuKhienSung.cs
- Gắn trên object: Súng bắn.
- Nhiệm vụ: đọc chuột/cảm ứng/Space bằng Input System mới, cập nhật hướng ngắm, bắn bóng, cho bóng bay.

Assets/Scripts/QuanLyGiaoDien.cs
- Gắn trên object: Canvas/Bộ điều khiển UI.
- Nhiệm vụ: cập nhật điểm, cấp độ, số bóng, bảng thua, bảng thắng, nút chơi lại.

Assets/Scripts/Bong.cs
- Gắn trên từng quả bóng.
- Nhiệm vụ: lưu Hàng, Cột, Mã màu, Hướng bay.

Assets/Scripts/ThuVienHinhAnhBong.cs
- Tạo và cập nhật hình ảnh bóng.
- Nếu có ảnh trong Resources/AnhBong thì dùng ảnh đó, nếu thiếu thì tự tạo sprite tròn.

Assets/Scripts/TienIchBanBong.cs
- Hàm tiện ích dùng chung: tạo object, thêm component, tạo hình chữ nhật, xóa object.

3. CÁCH CHỈNH SỬA NHANH

Muốn chỉnh số hàng/cột bóng:
- Chọn Quản lý trò chơi.
- Sửa So Hang, So Cot, So Hang Ban Dau trong Inspector.

Muốn chỉnh tốc độ bắn:
- Chọn Quản lý trò chơi.
- Sửa Toc Do Ban.

Muốn chỉnh tường, nền:
- Chọn Nền chính hoặc Tường > Tường trái / Tường phải / Tường trên.
- Sửa SpriteRenderer hoặc Transform.

Muốn chỉnh UI:
- Mở Canvas.
- Chỉnh Khung điểm, Khung cấp độ, Khung bóng, Bảng thua, Bảng thắng.

4. NẾU UNITY CHƯA HIỆN OBJECT NGAY

- Mở Scene: Assets/Scenes/BanBong.unity
- Chọn object Quản lý trò chơi.
- Bật Hien Tat Ca Object Truoc Khi Play.
- Bấm Ctrl + S để lưu Scene.
